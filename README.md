# Социальная платформа для создания постов и сообществ

## Описание проекта
Эта социальная платформа предназначена для пользователей, которые хотят создавать, делиться постами и взаимодействовать в сообществах по интересам.

## Основные функции
- 🏠 **Главная страница**: общее представление контента и последних обновлений.
- 📝 **Создание и редактирование постов**: пользователи могут добавлять новые посты или изменять существующие.
- 🗂 **Сообщества по интересам**: возможность создания и участия в группах по интересам.
- 👤 **Персональные профили пользователей**: каждый пользователь имеет страницу со своей информацией.
- 🔐 **Система регистрации и авторизации**: безопасный доступ к платформе.
- ⚙️ **Админ-панель**: инструменты для управления контентом и пользователями.
- 🛠 **Создание новых сообществ и постов**: интуитивно понятные формы для создания контента.
- 📄 **Страница "Обо мне"**: информация о пользователе и его активности.

## Технологии
- Python 3.8+
- Django 4.0+
- PostgreSQL
- HTML5
- JavaScript

## Установка и запуск 
**Клонировать репозиторий:**
   ```bash
   git clone https://github.com/31ISR/up09-lab5-charushin.git
   cd up-09-lab5-charushin
   ```
## Создать и активировать виртуальное окружение:
    ```bash
    python -m venv venv
    source venv/bin/activate # Linux/MacOS
    venv\Scripts\activate.bat # Windows
    ```

## Установить зависимости:
    ```bash
    pip install -r requirements.txt
    ```

## Настройка окружения: Создайте файл .env в корне проекта со следующим содержанием:
    ```plaintext
    SECRET_KEY=ваш-секретный-ключ
    DEBUG=True
    DATABASE_URL=postgres:///ваша-база-данных
    ```
## Применить миграции:
    ```bash
    python manage.py migrate
    ```
## Создать суперпользователя:
    ```bash
    python manage.py createsuperuser
    ```
## Запустить сервер:
    ```bash
    python manage.py runserver
    ```
## Доступные страницы
- / - Главная страница
- /post_page/ - Все посты
- /communities/ - Список сообществ
- /post_new/ - Создать пост
- /communities_new/ - Создать сообщество
- /register/ - Регистрация
- /login/ - Авторизация
- /about/ - Обо мне
## Админ-панель
Админка доступна по адресу /admin/. Для доступа необходимо:

Выполнить команду createsuperuser
Войти с логином и паролем суперпользователя

Возможности админки:
- Управление пользователями
- Модерация постов
- Управление сообществами
- Просмотр статистики
- Редактирование любых моделей
